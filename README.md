# منيو ولوحة تحكم عصملي - OSMANLI (ABU SEIR 1854) | نابلس 🥮

مشروع المنيو الرقمي ولوحة إدارة الأصناف والمحتوى لمحل **عصملي - أبو سير 1854** (نابلس - رفيديا - مقابل الأكاديمية).
مبني بلغة **PHP 8.2** و **MySQL (MariaDB)** مع استخدام تقنية **PDO** الآمنة للحماية من ثغرات الحقن (SQL Injection).

---

## 🌟 هيكلية النظام وميزاته

### 1. المنيو العام للزبائن (`index.php`)
- يعرض الأصناف **المتوفرة فقط** (`is_available = 1`) ديناميكياً من قاعدة البيانات.
- واجهة بصرية فاخرة متجاوبة مع الهواتف الذكية (Mobile-First) بالطابع العثماني الأخضر الزمردي والذهبي.
- خالية تماماً من أزرار الشراء أو السلال (View-Only Digital Showcase Menu).
- لا يظهر أي أزرار تحكم أو تعديل أو حذف للزوار العاديين.
- كارت باركود عالي الدقة (800x800) مخصص لطاولات المطعم (Table Tents).

### 2. لوحة تحكم المشرفين (`admin_menu.php`)
- **محمية بالكامل** عبر الوسيط `auth_check.php` للتحقق من صلاحية الجلسة (`role === 'admin'`).
- **إحصائيات فورية (KPIs):** إجمالي الأصناف، الأصناف المتوفرة، الأصناف المخفية، وعدد الأقسام.
- **إضافة صنف جديد (Create):** نموذج لإدخال الاسم، السعر، القسم، الوصف، وإمكانية رفع صورة جديدة تُحفظ تلقائياً في مجلد `uploads/`.
- **تعديل صنف (Update):** تعديل كافة بيانات الصنف، مع خيار استبدال الصورة أو الإبقاء على الصورة الحالية.
- **تبديل التوفر السريع (Toggle Availability):** إخفاء أو إظهار الصنف في المنيو العام بنقرة زر واحدة دون الحاجة لحذفه.
- **حذف صنف (Delete):** حذف الصنف نهائياً مع نافذة تأكيد تحذيرية باللغة العربية (Confirmation Modal).
- **بحث وفلترة فورية:** فلترة حسب الأقسام، الحالة (متوفر/مخفي)، مع شريط بحث فوري أثناء الكتابة.

### 3. الأمان وتسجيل الدخول (`login.php` & `logout.php`)
- صفحة دخول بتصميم عثماني متناسق.
- تشفير كلمات المرور باستخدام خوارزمية BCRYPT المعتمدة (`password_hash` و `password_verify`).
- حماية الجلسات وتجديد معرّف الجلسة (`session_regenerate_id`).
- تسجيل الخروج الآمن وتدمير ملفات تعريف الارتباط والجلسات (`logout.php`).

## 🗄️ قاعدة البيانات (Database Schema)

قاعدة البيانات: `osmanli_db` (UTF-8 / utf8mb4)

### جدول المشرفين (`users`)
| الحقل | النوع | الوصف |
|---|---|---|
| `id` | INT AUTO_INCREMENT | المفتاح الأساسي |
| `username` | VARCHAR(50) UNIQUE | اسم المستخدم |
| `email` | VARCHAR(100) UNIQUE | البريد الإلكتروني |
| `password_hash` | VARCHAR(255) | كلمة المرور المشفرة بـ BCRYPT |
| `role` | VARCHAR(20) | الصلاحية (الافتراضي: 'admin') |
| `created_at` | TIMESTAMP | تاريخ الإنشاء |

### جدول المنيو والأصناف (`menu_items`)
| الحقل | النوع | الوصف |
|---|---|---|
| `id` | INT AUTO_INCREMENT | المفتاح الأساسي |
| `name` | VARCHAR(150) | اسم الصنف |
| `description` | TEXT | المكونات وطريقة التقديم |
| `price` | DECIMAL(10, 2) | السعر بالشيكل (₪) |
| `category` | VARCHAR(100) | القسم (كنافة، حلويات شرقية، إلخ) |
| `image_url` | VARCHAR(255) | مسار الصورة (`images/...` أو `uploads/...`) |
| `is_available` | TINYINT(1) | حالة التوفر للزبائن (1 = متوفر، 0 = مخفي) |
| `created_at` | TIMESTAMP | تاريخ الإضافة |
| `updated_at` | TIMESTAMP | تاريخ آخر تعديل |

## 🚀 طريقة التثبيت والتشغيل المحلي

### 1. تشغيل خادم MySQL:
تأكد من تشغيل خادم MySQL (عبر XAMPP أو MariaDB) على المنفذ الافتراضي `3306`.

### 2. تهيئة قاعدة البيانات وزرع الأصناف:
يمكنك استيراد قاعدة البيانات بإحدى الطريقتين:
- **الطريقة الأولى (التلقائية عبر المتصفح):** افتح الرابط: `http://localhost:8888/setup.php` وسيتم إنشاء القاعدة وزرع الحساب والأصناف فوراً.
- **الطريقة الثانية (عبر سطر الأوامر):**
  ```bash
  mysql -u root -p < schema.sql
  ```

```bash
php -S 127.0.0.1:8888
```
